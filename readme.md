## What is `generate.py`

This file is used to generate everything inside of `./src/generated/`.
To use it simply do `python generate.py <where 'GeometryDash.bro' is>`:

```sh
python generate.py "D:\Geode\bindinds\bindings\2.2074"
```

You'll need a broma file for this to work, so technically, you could make this work on older geode/gd versions *(maybe, I have 0 idea)*
